Política de privacidad

Última actualización: 22 de noviembre de 2026 · Responsable: Edison Parra, HopGol Studio.

Qué es este sitio

Este sitio presenta HopGol Studio. No tiene formularios de registro, analítica propia ni carga de archivos. GitHub Pages aloja la web y puede tratar datos técnicos de acceso conforme a sus propias políticas.

Datos tratados por la aplicación local

En el computador donde funciona el Studio se guardan proyectos, guiones, recursos multimedia, archivos de video, configuración y el estado de publicaciones. Si conectas una red social mediante OAuth, la aplicación recibe los identificadores y tokens que permite esa plataforma para identificar la cuenta y realizar las acciones autorizadas. No solicita ni almacena la contraseña de tu red social.

Finalidad y almacenamiento

La aplicación usa esos datos para preparar videos, mostrar el estado de tus cuentas conectadas, renovar los permisos cuando corresponda y enviar una publicación después de tu aprobación. Las credenciales sociales se guardan cifradas en el equipo mediante Windows DPAPI para el usuario de Windows que ejecuta el Studio. El contenido de producción se conserva localmente hasta que el usuario lo elimine.

Servicios externos

Al investigar noticias o buscar recursos, el Studio puede consultar proveedores externos. Al conectar una cuenta, el navegador te dirige al servicio de la red social para autorizar el acceso. Al aprobar una publicación, el video y los datos de la publicación se envían a la plataforma seleccionada, que los trata según sus propias políticas. El sitio público se aloja en GitHub Pages.

Permisos, conservación y eliminación

Puedes revocar el acceso de HopGol Studio desde la configuración de la red social. Para eliminar copias locales de tokens, proyectos o videos, debes retirarlas del equipo donde usas el Studio; revocar un permiso en la red social no borra automáticamente esos archivos. Una publicación ya enviada se gestiona y elimina desde la red social correspondiente.

Contacto

Para consultas sobre privacidad o solicitudes relacionadas con el Studio, contacta al responsable a través de su perfil de GitHub. Evita incluir tokens o datos sensibles en publicaciones públicas.
